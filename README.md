# Ascend Landing

Standalone marketing landing page for Ascend, decoupled from the
Ascend Admin app.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- lucide-react icons

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Routes

- `/` — landing page
- `/signin` — placeholder sign-in (the real workspace lives in Ascend Admin)
- `/terms` — Terms & Conditions
- `/privacy` — Privacy Policy

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run typecheck
```
